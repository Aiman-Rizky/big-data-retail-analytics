# Data

Dataset lengkap disimpan di luar repository karena ukurannya besar. Unduh dataset dari Kaggle, lalu susun folder sesuai petunjuk pada README utama.

Folder `sample/` digunakan untuk sampel kecil yang aman di-commit. Buat sampel dengan:

```powershell
python scripts/create_sample.py --rows 10000
```

Sampel hanya digunakan untuk demonstrasi struktur dan pengujian cepat. Insight akhir harus dihitung dari data penuh atau ukuran data yang disebutkan secara eksplisit.
